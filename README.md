# Student Placement Prediction System

## Project Overview
This project predicts whether a student will be placed based on academic and skill parameters such as CGPA, internships, projects, aptitude score, and communication skills.

## Features
- Synthetic data generation
- Machine learning model training
- Placement prediction interface
- SQL database integration
- Model retraining pipeline
- Interactive dashboard

## Tech Stack
- Python
- Scikit-learn
- Streamlit
- SQLite
- Pandas
- GitHub (Version Control)

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
